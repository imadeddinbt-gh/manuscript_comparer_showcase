# 📜 مقارن المخطوطات (Manuscript Comparer)

أداة احترافية متقدمة مبنية بلغة بايثون (Python) لمقارنة النصوص والمخطوطات العربية، مع واجهة مستخدم رسومية (GUI) تفاعلية. تهدف الأداة إلى تسهيل عمل المحققين والباحثين في التراث الإسلامي والعربي من خلال استخراج الفروق بين النسخ المختلفة بدقة عالية مع إمكانية تجاهل الفروق الإملائية والنحوية.

## ✨ المميزات الرئيسية

* **واجهة رسومية تفاعلية**: واجهة سهلة الاستخدام تتيح رفع الملفات ومقارنتها بضغطة زر.
* **دعم السحب والإفلات**: إمكانية سحب وإفلات الملفات مباشرة إلى الواجهة.
* **دعم ملفات Word**: إمكانية قراءة النصوص مباشرة من ملفات الوورد (`.docx`).
* **تطبيع النص العربي (Text Normalization)**:
  * تجاهل التشكيل (الحركات) والتطويل.
  * تجاهل الفروق الشائعة مثل التاء المربوطة والهاء (مدرسة / مدرسه).
  * توحيد أشكال الألف (أ، إ، آ، ا).
  * تجاهل الهمزات المتطرفة أو الوسيطة.
* **خيارات مقارنة متقدمة مرنة**:
  * إمكانية تجاهل علامات الترقيم، والأرقام، والفراغات.
  * إمكانية تجاهل "ال" التعريف، و"واو" العطف، والكلمات المفتاحية المكررة (Stop words) مثل: "قال"، "حدثنا"، "أخبرنا".
  * تجاهل الأقواس وما بداخلها (مثل الجمل الاعتراضية: صلى الله عليه وسلم).
  * تجاهل الياء المقصورة والمنقوطة.
* **تقارير مفصلة**: تصدير نتائج المقارنة والفروق إلى ملفات Excel (`.xlsx`) وملفات نصية (`.txt`).
* **عرض ذكي للنتائج**: نافذة مخصصة لعرض الفروق بشكل منسق مع تحديد الإضافات والحذف.

## 🛠️ التقنيات المستخدمة

* **اللغة**: Python 3
* **المكتبات الأساسية**: 
  * `difflib`: لإجراء المقارنات واستخراج الفروق بدقة.
  * `re`: للتعامل مع التعابير النمطية (Regex) لتنظيف وتطبيع النص العربي.
  * `python-docx`: لقراءة ملفات الوورد واستخراج النصوص.
  * `tkinter`: لبناء الواجهة الرسومية.
